# Results

This folder contains experiment outputs reported in the paper.

## Expected Structure

| Folder | Description |
|---|---|
| `performance_tables/` | RMSE, MAE, NRMSE, OOD degradation, and related summary tables. |
| `ablation_outputs/` | Cross-propagation and Physics-IINN ablation outputs. |
| `figures/` | Generated result figures used in the manuscript or supplementary material. |

## Notes

Results should be linked to the corresponding experiment configuration, dataset split, and random seed where available. This helps readers verify which outputs correspond to city shift, frequency shift, restricted training data, and cross-propagation transfer.
