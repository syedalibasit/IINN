# Terrain Profiles

This folder contains example terrain and clutter profiles along selected transmitter--receiver or site-to-site paths.

## Purpose

Terrain profiles show how local obstructions, building morphology, vegetation, and elevation changes affect propagation. They help explain why RSRP may deviate from a smooth distance-dependent trend in dense urban environments.

## Suggested Files

| File | Description |
|---|---|
| `brussels_site0_site3_profile.png` | Example terrain and clutter profile between two Brussels sites. |
| `brussels_ue_site_profile_short_range.png` | Example UE-to-site profile at shorter range. |
| `brussels_ue_site_profile_long_range.png` | Example UE-to-site profile at longer range. |

## Interpretation

These profiles support the physical consistency discussion by showing that local clutter and obstruction effects can introduce RSRP variation beyond distance loss alone.
